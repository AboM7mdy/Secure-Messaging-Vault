
SecureVault is a local secure messaging and file vault system for CS320 Computer Security.

## Features
- AES-based message encryption and decryption
- File encryption and decryption
- Password-based key handling
- Wrong-password attack demo
- Functional tests

## How to Run
Install Python 3.10 or newer.
Open a terminal inside this folder.
pip install -r requirements.txt
python3 app.py

## How to Run Tests
python3 run_tests.py
